# 120 Years of Olympic History Analysis | SQL, Excel, Power BI

## Project Overview
Cleaned and validated a 135,000+ record dataset covering 
120 years of Olympic Games, building interactive Power BI 
dashboards tracking medal trends, gender participation 
growth, and country performance.

## Tools Used
- SQL — data querying and analysis
- Excel — data cleaning and preprocessing  
- Power BI — interactive dashboard (Dashboard.pbix)

## Dataset
Athletes and events data covering Olympic Games 
from 1896 to 2016.
